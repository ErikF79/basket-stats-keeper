# **App Name**: Basket Stats Keeper

## Core Features:

- Team Setup: Allow the user to add player names and team name
- Real-Time Stats Tracking: Record and display real-time statistics such as points, assists, rebounds, and fouls for a single player or team
- Live Dashboard: Provide a clear, customizable dashboard for displaying live game stats and player performance. 
- Performance Analysis (AI): Summarize key stats and suggest improvements based on trends (tool).
- PWA Support: PWA compatibility to install the app to home screen

## Style Guidelines:

- Primary color: A saturated blue (#29ABE2) to represent focus, clarity, and energy.
- Background color: A light blue, almost white (#E0F7FA), to ensure readability and reduce eye strain.
- Accent color: A contrasting orange (#FF8A65) for important stats and interactive elements, to highlight key performance indicators.
- Body and headline font: 'Inter', a sans-serif font, providing a clean and modern look.
- Use clean, outlined icons to represent different stats and actions. Consistent style for easy recognition.
- Prioritize key stats on the dashboard for quick reference. Use clear sections for different types of data.
- Subtle animations or transitions when stats are updated to provide a smooth user experience.
